# 每日资产监控看板

自包含单页 HTML（ECharts 深色终端风），美股交易日更新。

- **线上访问**：打开仓库后启用 GitHub Pages，访问 `https://possbb.github.io/market-dashboard/`
- **数据**：美股个股（JD/NVDA/SPCX）、汇丰美股指数 U50009（标普500近似）、黄金（含人民币金价自动换算）、人民币核心汇率（USD/EUR/HKD vs CNY 央行中间价）、美国 10Y/2Y 国债收益率与 2s10s 利差、中国 10Y 国债与 DR007、北京/巴塞罗那房价租金（含租售比）、京东基金组合 9 只
- **更新方式**：修改 `index.html` 内 `ASSETS` 数据对象后推送即可
